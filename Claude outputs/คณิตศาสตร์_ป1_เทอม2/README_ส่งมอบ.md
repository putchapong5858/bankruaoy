## 3. ทำตามข้อกำหนดของครูครบทุกข้อ

- ไม่มีพื้นสีทึบเข้ม ใช้พื้นอ่อนคู่ตัวอักษรเข้มคมชัด ประหยัดหมึก
- ตัวเลือกคำตอบกระจายเต็มความกว้างของข้อ ไม่วางชิดกัน
- ลายน้ำเฉพาะแถบบนกับแถบล่าง ขนาด 11pt ความทึบ 4.5%
- เฉลยแยกไว้หน้าท้ายชุด มีเส้นประ ✂ ให้ตัดออกก่อนแจกเด็ก
- เลขอารบิกเป็นหลัก เลขไทยใช้กับเลขข้อและเลขหน้า
- ทุกหน้าพอดี A4 ไม่มีเนื้อหาล้นหน้า

## 4. การตรวจสอบคุณภาพที่ทำไปแล้ว

ทุกบทผ่านโปรแกรมตรวจอัตโนมัติ (`verify.py`) ซึ่งตรวจ

1. ทุกข้อมีตัวเลือกครบ 4 ตัว ไม่มีตัวเลือกซ้ำภายในข้อ
2. เฉลยกระจายในช่อง ก ข ค ง ใกล้เคียงกัน (20 ข้อ = ช่องละ 5 พอดี)
3. การหมุนตำแหน่งตัวเลือกแล้วเฉลยยังตรงเดิม
4. ทุกข้อมีคำอธิบายเฉลย
5. ไม่มีโจทย์ซ้ำกันภายในชุดเดียวกันและข้ามชุดภายในบท
6. ใบงานทุกรูปแบบไม่มีโจทย์ซ้ำกัน และเฉลยมีจำนวนข้อตรงกับโจทย์ทุกหน้า
7. ทุกหน้า PDF ไม่ล้นกระดาษ
8. ข้อกำหนดการพิมพ์ครบ (ลายน้ำ พื้นสี ตัวเลือก เส้นประ)

**เพิ่มเติม** — ผลบวก ผลลบ และเฉลยเชิงตัวเลขทุกข้อ
คำนวณด้วยโปรแกรม ไม่ได้พิมพ์เอง และมีการตรวจเงื่อนไขซ้ำ เช่น

- บทที่ 12 ตรวจว่าผลบวกทุกข้อไม่เกิน 100 และข้อที่ระบุว่า "มีการทด"
  มีการทดจริงทุกข้อ
- บทที่ 13 ตรวจว่าตัวตั้งทุกข้อมากกว่า 20 แต่ไม่เกิน 100
  ผลลบไม่ติดลบ และข้อที่ระบุว่า "ต้องกระจาย" ต้องกระจายจริง
- บทที่ 14 ตรวจว่าคำตอบทุกข้ออยู่ในช่วง 0 ถึง 100

## 5. ขอบเขตเนื้อหาอ้างอิงจากไหน

ยืนยันจาก**ไฟล์หนังสือ สสวท. ที่ครูส่งให้เอง** (`ป.1 เล่ม 2 บทที่ 8-14.pdf`)
โดยอ่านตาราง "จุดประสงค์การเรียนรู้" ท้ายบทของแต่ละบทโดยตรง
ตารางนี้ถอดไว้ครบในหน้า "ตารางวิเคราะห์จุดประสงค์การเรียนรู้รายบท"
ของส่วนหน้ารูปเล่ม

แหล่งอ้างอิงอื่นที่ใส่ไว้ในหน้าบรรณานุกรม

- กระทรวงศึกษาธิการ. ตัวชี้วัดและสาระการเรียนรู้แกนกลาง กลุ่มสาระการเรียนรู้
  คณิตศาสตร์ (ฉบับปรับปรุง พ.ศ. 2560)
- สสวท. หน้ารวมเอกสารหลักสูตร https://www.ipst.ac.th/curriculum
- สพม. เขต 12. มาตรฐานการเรียนรู้และตัวชี้วัด
  http://www.sea12.go.th/spv/images/PDF/learningstandards.pdf
- สสวท. คู่มือการใช้หลักสูตรคณิตศาสตร์ ระดับประถมศึกษา (scimath.org)
- DLTV เอกสารประกอบการสอนคณิตศาสตร์ ป.1 https://www.dltv.ac.th

**ข้อควรทราบที่ต้องบอกตรง ๆ** — แหล่งที่ผม**ตรวจสอบเนื้อหาด้วยตัวเองได้จริง**
คือไฟล์ สสวท. ที่ครูส่งมาเท่านั้น ส่วนรายการอื่นเป็นเอกสารหลักสูตร
ที่ค้นเจอและใส่ไว้ให้ครูตามรอยต่อได้ แต่ผมเปิดอ่านเนื้อหาข้างในไม่สำเร็จ
(บางแหล่งเป็น PDF ที่ระบบดึงข้อความไม่ออก) จึงไม่ได้อ้างข้อความใด
จากเอกสารเหล่านั้น

## 6. เรื่องลิขสิทธิ์

โจทย์ ภาพประกอบ และเฉลยทุกชิ้น**เขียนและวาดขึ้นใหม่ทั้งหมด**
ภาพรูปเรขาคณิต เส้นจำนวน ไม้บรรทัด แท่งสิบ บันไดบวก และตารางจำนวน
วาดด้วยโปรแกรมเป็นภาพเวกเตอร์ ไม่ได้สแกนหรือคัดลอกจากที่ใด
ใช้เพียงขอบเขตเนื้อหาและจุดประสงค์การเรียนรู้ซึ่งเป็นสาระของหลักสูตร
มาเป็นกรอบ จึงนำไปจัดพิมพ์เผยแพร่ต่อสาธารณชนได้

## 7. ถ้าจะทำต่อ

ไฟล์ต้นฉบับใน `MathP1_Term2_source.zip` จัดไว้ให้ทำบทใหม่ได้ง่าย

```
mathp1/
  layout.py     โครงหน้ากระดาษกลาง ใช้ร่วมกันทุกบท
  draw.py       ภาพประกอบ SVG ทั้งหมด (รูปทรง เส้นจำนวน ไม้บรรทัด ฯลฯ)
  engine.py     เครื่องสร้างเอกสาร แบ่งหน้าอัตโนมัติ ออก PDF
  check.py      ชุดตรวจงานกลาง
  shot.py       แคปหน้าจอหน้าใดหน้าหนึ่งไว้ตรวจด้วยตา
  bundle.py     รวมเล่มและบีบอัดไฟล์
  ch08 … ch14/  sheets.py (ใบงาน) + exams.py (ข้อสอบ) + build.py + verify.py
  final/        ข้อสอบรวบยอด
  front/        ส่วนหน้ารูปเล่ม
```

ทำบทใหม่ = สร้างโฟลเดอร์ `ch15/` แล้วเขียนแค่ `sheets.py` กับ `exams.py`
ที่เหลือใช้ของเดิมได้ทั้งหมด
